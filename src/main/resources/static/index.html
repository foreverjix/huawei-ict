      玩法说明

      3 分钟上手
      1. 开启摄像头

        点击页面中央的「开启摄像头」按钮，允许摄像头权限，正坐 2 秒完成姿态校准。右侧面板也会显示实时识别状态。

      2. 张嘴开局

        张嘴一次（或按空格）进入沉浸模式，镜头会下潜到游戏海域。一组训练 90 秒，分热身、主训、放松三段。

      3. 跟着鱼的方向转头

        鱼会从需要活动的方向游来：左侧的鱼要向左转头，右侧的鱼要向右转头，中间的金色方向环是目标。蓝色鱼在画面中间，代表回正休息。主训段还会各来一条上方和下方的鱼，对应抬头后伸与低头，幅度比左右更小。

      4. 做「到位」的那一下

        转头幅度达到目标角度的 85% 以上时，锁定环会变成金色，收益更高；没到位也能吃，但只拿基础分。转头过快（超过 70°/秒）会暂时失去锁定并提示「慢一点」。

      5. 张嘴吸鱼

        张嘴一次开启 2.2 秒吸气窗口，窗口内扫过的锁定鱼会被连续吞掉；一直张着嘴会持续延期。

      6. 推进任务

        金色任务鱼推进当前任务进度，蓝色归中鱼只是休息。越靠画面边缘的鱼基础价值越高，最高 ×3。

      7. 一组结束看小结

        90 秒后给出左右转头次数、峰值角度与配平结果。某一侧做得少，下一组会优先补那一侧。

      8. 退出

        按 Esc 或点击顶部 HUD 的「退出游戏」，回到首页布局。

      健康提示：动作放慢、幅度循序渐进，不要快速甩头，仰头不超过 15°。有颈椎病史、眩晕史请先咨询医生，本功能仅为活动引导，不是治疗。
