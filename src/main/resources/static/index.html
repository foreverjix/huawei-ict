玩法说明

3 分钟上手
  1. 开启摄像头

    点击右侧「专注监测」的开始按钮，允许摄像头权限，正坐 2 秒完成姿态校准。

  2. 张嘴开局

    张嘴一次（或按空格）进入沉浸模式，镜头会下潜到游戏海域，之后才开始出鱼。

  3. 晃动头部瞄准

    左右、上下移动头部控制准星。鱼进入准星范围时，会出现绿色脉冲光环表示已锁定。

  4. 张嘴吸鱼

    张嘴一次开启 2.2 秒吸气窗口，窗口内扫过的锁定鱼会被连续吞掉；一直张着嘴会持续延期。

  5. 推进任务

    金色任务鱼推进当前任务进度，蓝色缓冲鱼只是休息。越靠画面边缘的鱼价值越高，最高 ×3。

  6. 退出

    按 Esc 或点击顶部 HUD 的「退出游戏」，回到首页布局。

健康提示：动作放慢、幅度循序渐进，不要快速甩头。有颈椎病史、眩晕史请先咨询医生，本功能仅为活动引导，不是治疗。
